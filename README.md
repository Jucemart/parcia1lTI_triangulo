# Proyecto: Cálculo de Área de un Triángulo

Este es un proyecto en Java utilizando Maven, diseñado para calcular el área de un triángulo mediante la fórmula base * altura / 2. 

## Tecnologías Utilizadas
- Java
- Maven
- JUnit (para pruebas unitarias)
- Git y GitHub para control de versiones

## Estructura del Repositorio
- 'main': Rama principal, vacía según lo requerido.
- 'develop': Contiene el código base, README y licencia.
- 'feature': Implementación de la función para calcular el perímetro.

## Instalación y Ejecución
1. Clonar el repositorio:
   ```bash
   git clone https://github.com/Jucemart/parcia1lTI_triangulo.git
   ```
2. Navegar al directorio del proyecto:
   ```bash
   cd parcia1lTI_triangulo
   ```
3. Compilar y ejecutar:
   ```bash
   mvn clean install
   mvn exec:java
   ```

## Pruebas Unitarias
Para ejecutar los tests unitarios con JUnit:
```bash
mvn test
```
